# История изменений

[English](CHANGELOG.md) | **Русский**

Все заметные изменения DX Cluster Client собраны в этом файле. Формат вдохновлён
[Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), проект следует
[семантическому версионированию](https://semver.org/lang/ru/).

## [Unreleased]

## [0.4.1] — 2026-11-22

### Добавлено

- Схема архитектуры в `docs/` (SVG и PNG-превью).

### Исправлено

- Alarm: при удалении выбранного совпадения по возрасту таблица перескакивала на последнюю строку
  (самый старый спот); теперь позиция прокрутки сохраняется, а снятое выделение очищается.
- Таблица Spots сохраняет позицию прокрутки при удалении старых спотов — так же, как Alarm.
- Целочисленные настройки вне допустимого диапазона ограничиваются при загрузке; отрицательный
  возраст больше не очищает таблицы.
- Атомарная запись исправляет права старого `.tmp`, поэтому `settings.json` остаётся `0600`.
- Адрес кластера проверяет порт (1..65535) и поддерживает IPv6 в квадратных скобках.
- После обновления `cty.dat` пересчитываются флаги Alarm и убираются переставшие совпадать споты;
  более старая версия не принимается, а предыдущий файл сохраняется как `cty.dat.bak`.
- Счётчик непрочитанных Alarm ограничивается при удалении совпадений; Clear сбрасывает его,
  а Clear all — ещё и историю повторных уведомлений.
- Подключение прерывается по таймауту через 15 секунд и уходит в обычное переподключение.

## [0.4.0] — 2026-11-19

### Добавлено

- Changelog на английском и русском языках.
- Скриншоты в README на английском и русском языках.
- CI-прогон тестов на push и pull request (Linux и Windows, Python 3.10 и 3.12).
- Колонка «Возраст» и копирование выделенных спотов по Ctrl+C.
- Таблица спотов запоминает ширины и порядок колонок, а также сортировку.

### Изменено

- README обновлены: поведение Alarm, счётчик повторов, обновление списка кластеров,
  структура проекта.
- Запись `settings.json` и `cty.dat` теперь выполняет `fsync` перед атомарным переименованием.
- Настройки сохраняются с небольшой задержкой, а не при каждом изменении фильтра.
- CI дополнительно запускает `ruff`.

### Исправлено

- Alarm: удаление или отключение правила теперь убирает из вкладки Alarm уже собранные по нему
  споты и сбрасывает счётчик непрочитанного; раньше совпадения оставались до удаления по возрасту
  (24 ч) или ручной очистки, из-за чего казалось, что споты продолжают приходить.
- Повреждённые записи `custom_clusters` и нестроковые значения геометрии окна больше не мешают
  запуску приложения.
- Кэш списка кластеров записывается атомарно.
- После обновления `cty.dat` обновляются списки стран и сущности уже показанных спотов.

## [0.3.2] — 2026-11-17

### Добавлено

- Alarm: позывные и маски автоматически вводятся заглавными; названия стран сохраняют регистр.
- Alarm: список правил сортируется по имени кнопкой «Сортировать по имени» или кликом по заголовку
  «Позывной / маска»; порядок сохраняется.
- Alarm: одинаковое правило нельзя добавить дважды — выводится предупреждение (совпадение по типу
  и шаблону без учёта регистра); редактируемое правило не считается дублем самого себя.

### Исправлено

- Исторические споты из `sh/dx` сохраняются, но до калибровки часов ПК не считаются свежими:
  не вызывают Alarm, не пересылаются в логгеры и не удаляются по возрасту.
- Повреждённые `clusters.json` и `settings.json` больше не мешают запуску; значения неверного типа
  заменяются значениями по умолчанию, а неподходящие элементы списков отбрасываются.
- `settings.json` записывается атомарно с правами только для владельца (`0600`); обновление
  `cty.dat` тоже атомарное.
- Фильтрация и поиск работают на PySide6 6.6–6.8 (совместимость с версиями Qt без
  `beginFilterChange`).
- Таблица спотов использует индекс по позывному для точных и дублирующих проверок, удаляет строки
  непрерывными диапазонами и ограничивает максимальное число строк.
- Исправлено падение тестов при завершении на PySide6 6.12.

## [0.3.1] — 2026-11-17

### Добавлено

- Поправка часов: возраст спотов считается по времени кластера (медианное смещение живых спотов);
  в статусной строке появляется предупреждение, если часы ПК расходятся больше чем на 5 минут.
- Сторожевой таймер соединения: переподключение после 15 минут без данных.
- Совпадения Alarm старше 24 часов удаляются автоматически (срок настраивается); кнопка «Очистить»
  на вкладке «Споты» и «Вид → Очистить все споты и совпадения Alarm» (Ctrl+L).

### Изменено

- Проверка обновлений и свежести `cty.dat` перепроверяется раз в час при долгой работе.
- Декодирование строк работает на уровне байтов: символы UTF-8 и telnet-команды, разделённые
  между TCP-пакетами, обрабатываются корректно; есть запасной вариант cp1251.
- Приглашение telnet-сервера использует дату, не зависящую от локали.

### Исправлено

- Одинаковые споты (например, повторный `sh/dx` после переподключения) игнорируются.
- Повреждённый `settings.json` сохраняется как резервная копия и показывается в сообщении,
  а не перезаписывается молча.
- История уведомлений Alarm очищается, чтобы не расти бесконечно.

## [0.3.0] — 2026-11-16

### Добавлено

- Солнечные индексы (SFI, A, K и число пятен) на панели инструментов; обновляются раз в час
  с hamqsl.com, запасной источник — NOAA SWPC.
- Колонки азимута и расстояния по QTH-локатору из настроек.
- Поиск по позывному или стране над таблицей спотов.
- Диалог «Дать спот…», в том числе из контекстного меню спота.
- Журнал ошибок `dxclient.log` и окно для непойманных исключений.
- Ежедневная проверка обновлений на GitHub и автообновление `cty.dat`, если он старше 30 дней.
- Настройки на вкладках.

### Изменено

- В колонке вида, кнопках фильтров и списке Alarm показывается **PH** вместо SSB/AM/FM.
- Старые споты (например, из `sh/dx` после входа) показываются, но не вызывают Alarm и не
  пересылаются в логгеры; споты старше заданного срока удаляются, а с половины срока показываются
  серым.
- Повторные споты станции на том же диапазоне и виде объединяются в одну строку со счётчиком.
- Тесты для новой логики.

## [0.2.0] — 2026-11-16

### Добавлено

- Встроенный telnet-сервер для логгеров (N1MM, Log4OM, …) на `127.0.0.1:7300`; порт и доступ
  из локальной сети настраиваются.
- Сервер пересылает только споты, прошедшие текущие фильтры.
- Минимальный диалог кластера: приглашение позывного на `login:`, `sh/dx [n]` для отфильтрованной
  истории, `bye` для отключения.
- В статусной строке показывается адрес сервера и число клиентов или ошибка занятого порта.

### Изменено

- Исходные строки `DX de` пересылаются без изменений; строки `sh/dx` переформатируются.
- Тесты форматирования строк и сервера; обновлены README на английском и русском.

## [0.1.0] — 2026-11-16

### Добавлено

- Первый публичный релиз.
- Клиент telnet DX-кластера с кластером по умолчанию RA3CO-2 (`ra3co.com:7373`), автовходом
  и переподключением.
- Фильтры по диапазону, виду, континенту DX и спотера, стране; сохраняемые наборы фильтров.
- Alarm: список позывных, масок или стран со звуком и системными уведомлениями.
- Список кластеров с clusters.ra3co.com и свои узлы.
- Интерфейс на русском и английском.
- Сборки AppImage для Linux и один exe для Windows; лицензия MIT.
